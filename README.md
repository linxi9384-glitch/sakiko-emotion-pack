## 收录范围与核验

- 整理日期：2026-10-25。本包为精选集，不代表搜遍所有图片。
- 共下载并查看 266 张候选；剔除人物不符、只有背影或局部、表情无法辨认及不适合本包的图片。
- 按解码后的图像像素去重，移除 0 张重复候选；保留画面相似但字幕不同的表情。
- 含《BanG Dream! It's MyGO!!!!!》与《Ave Mujica》的剧情截图，可能涉及剧透。
- 含少量同框、童年及舞台面具造型；「祥子出镜」不等于「画面只有祥子」。
- 分类结合祥子的表情、台词及聊天用途，属于主观整理，不代表角色唯一的剧情情绪。
- 原图保留原字幕、尺寸与文件内容；中文文件名仅增加原始索引 ID，便于查找。
- MyGO Meme Chat 中有 51 张重叠图片的原始下载链接已另行下载，且与本包图片解码像素一致。
- 完整图片来源、原索引 ID、剧集、下载地址、尺寸与 SHA-256 校验值见 [manifest.json](manifest.json)；精简清单见 [index.csv](index.csv)。
